# GoReady
Prepare today. Stay ready tomorrow.
GoReady is an offline-first emergency preparedness companion that helps individuals and families organize emergency bags, track supplies, and review important preparedness information.

## Key Features
* Manage multiple emergency bags
* Track supply quantities
* Monitor expiration dates
* Store emergency information
* Works offline
* Local notification reminders
