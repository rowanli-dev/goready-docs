# 使用指南

## GoReady 是什麼

GoReady 協助您整理防災準備資訊、管理防災背包與物資、接收物品到期提醒，並將重要的緊急應變資訊保存在您的裝置上，以便需要時查閱。

## 開始使用

1. 建立防災背包。
2. 加入防災物資。
3. 視需要設定有效期限與保固期限。
4. 如有需要，建立緊急聯絡卡。
5. 定期檢查並更新您的防災物資。

## 常見問題

### GoReady 是否需要網路連線？

大部分核心功能可離線使用，包括管理防災背包、物品與緊急聯絡卡。

部分功能可能需要網路或電信服務，例如開啟線上支援表單、傳送簡訊，以及作業系統提供的雲端備份。

### 我的資料會上傳到伺服器嗎？

GoReady 不會將您的防災資料庫或圖片上傳到開發者營運的伺服器。

依照您的裝置設定，資料可能由 iCloud Backup、Android Auto Backup 或裝置移轉功能備份及還原。App 也可能將經過限制及過濾的錯誤診斷資料傳送至 Sentry。

當您主動傳送安全回報簡訊或提交支援表單時，您選擇提供的內容將交由相應的簡訊、電信或表單服務處理。詳情請參閱隱私權政策。
